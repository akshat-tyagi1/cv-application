# CV Application

A CV/resume builder built with React.

## Features

- Add and edit personal information
- Add education details
- Add practical experience
- Add skills and achievements
- Preview the CV in a clean resume layout
- Edit and submit sections dynamically

## Tech Stack

- React
- JavaScript
- CSS
- Vite
